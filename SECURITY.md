# Security policy

## Supported version

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing credentials, personal data, exploit details, or a working proof of concept.

## Deployment boundary

Athan Hub is a local-network appliance. Do not forward it directly to the public internet. For remote access, use a trusted VPN and retain dashboard PIN protection.

The project never requires GitHub tokens, Wi-Fi credentials, private keys, timetable data, or MP3 files to be committed to the repository.
